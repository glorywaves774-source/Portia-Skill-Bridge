Restoring

  1. Create a new, empty PostgreSQL database and point DATABASE_URL at it.
  2. Run flask db upgrade with the same release that made the backup.
  3. Set the same BACKUP_ENCRYPTION_KEY, then run flask backup verify NAME and flask backup restore NAME.

Downloads are still encrypted; they can only be opened with the key. Uploaded photos and documents are kept in the storage bucket, not in these backups: turn on versioning for the bucket.
